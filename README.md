# Haven

Haven is an application for searching for restaurants based on intolerances based on OpenStreetMap data.

This project uses Laravel on the backend and Svelte 5 on the frontend.
The app docker container is build on top of the serversideup image https://serversideup.net/.
The database container uses the offical PostgreSQL 18 image with PostGIS installed aditionally.

## Setup

### 1. Add APP_KEY

Generate the app key either with the artisan command, if you have the artisan CLI installed on your system

```bash
   php artisan key:generate
```

or with a website like https://appkeyforlaravel.com/

Please add this APP_KEY to the [`.env.docker`](.env.docker) APP_KEY field.

### 2. Add OSM data

Because the OSM database table is created by running the osm2pgsql tool, you need to have a `data.osm.pbf` file in the
`database/osm` folder in order to start the application.
You can download this file for your area of interest from a provider
like [Geofabrik](https://download.geofabrik.de/).

### 3. Start the application

During startup, Laravel runs migrations, which import the OSM data into the database and create the necessary tables.
Also, a seeder with allergen and dietary tag data is run as well.
To configure the default values, please see [AllergenSeeder.php](database/seeders/AllergenSeeder.php)
and [DietaryTagSeeder.php](database/seeders/DietaryTagSeeder.php).

```bash
   docker compose up -d
```

Optionally, you can also seed the database with menu items generated by the Faker library.
See the [MenuItemSeeder.php](database/seeders/MenuItemSeeder.php) for the default configuration.

```bash
   docker compose exec app php artisan db:seed --class=MenuItemSeeder
```

A similar seeder for reviews is available as well, see [ReviewSeeder.php](database/seeders/ReviewSeeder.php).

```bash
   docker compose exec app php artisan db:seed --class=ReviewSeeder
```

### 4. Access the application

The application will be available at http://localhost:8080.
